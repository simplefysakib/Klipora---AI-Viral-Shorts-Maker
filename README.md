# Klipora AI 5.9.1

Klipora AI is an Android long-video-to-shorts maker. Paste a video link, let the AI analyze the complete timestamped transcript, and export focused 9:16 Shorts, Reels, or TikTok clips with synced captions and background processing.

## Latest release: 5.9.1 (version code 47)

This release includes the Universal Best Shorts Engine, which evaluates the complete video timeline and selects independently understandable clips with a clear hook, necessary context, complete explanation or event, payoff, and natural ending. Clips are limited to 60 seconds and avoid mid-sentence starts, incomplete answers, duplicate topics, and misleading context.

The workflow is language-agnostic. It detects the source language and writing system and preserves meaning, names, titles, hooks, narration metadata, and captions context across English, Hindi, Hinglish, Urdu, Arabic, Bengali, Punjabi, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam, Nepali, Spanish, Portuguese, French, German, Italian, Turkish, Russian, Ukrainian, Indonesian, Japanese, Korean, Chinese, and other languages.

YouTube age-restricted sources are identified early and receive a clear authorized-login message instead of repeated failed downloader retries. The app-version checker has been permanently disabled in 5.9.1, so stale remote data cannot show a false “new version available” notice.

## Features

- AI clip selection from long videos, streams, podcasts, gaming, vlogs, tutorials, and more
- Source-language-aware captions and structured narration metadata
- Word-synced animated captions and multiple caption styles
- 9:16, 1:1, and 16:9 framing with background processing
- Up to 1080p export in the premium build
- AI face tracking for supported podcast workflows
- Android 7.0+ support, Gemini and Groq API key configuration
